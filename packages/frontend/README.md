# AfroCreate Collective Frontend

A modern, African-themed Web3 platform for cultural creators built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- 🎨 **African-Inspired Design**: Wakanda-style UI with cultural patterns and colors
- 🌍 **Cultural Heritage**: Community-driven validation system
- 🎭 **Creator Profiles**: ENS integration with .afro domains
- 💰 **Project Funding**: Crowdfunding for African creative projects
- 🔗 **Web3 Integration**: Smart contract interactions and IPFS storage
- 📱 **Responsive Design**: Mobile-first approach with beautiful animations

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
src/
├── app/                 # Next.js 14 App Router
├── components/          # React components
│   ├── creators/        # Creator-related components
│   ├── projects/        # Project components
│   ├── cultural/        # Cultural validation components
│   ├── ens/             # ENS domain components
│   └── ui/              # UI components
├── hooks/               # Custom React hooks
├── styles/              # CSS and Tailwind styles
└── utils/               # Utility functions
```

## Design System

The UI uses an African-inspired design system with:
- **Colors**: Wakanda purple, African gold, earth tones
- **Typography**: Exo 2 for body text, Orbitron for headings
- **Patterns**: Kente, Adinkra, and tribal motifs
- **Animations**: Floating elements and cultural transitions
